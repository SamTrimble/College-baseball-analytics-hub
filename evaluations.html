Signature feature · Player Evaluation Studio

Evaluation Studio

Build a scouting and development report in five steps: choose a template, load and map your CSV, pick a player, generate the report, then print or export it. Every number is calculated from your data in this browser.

Data source

Use the active dataset or upload a new CSV for this evaluation

Template requirements

Column mapping

Auto-detected matches are pre-filled. Change any dropdown if your column names differ.

Print

Prints a clean, white "paper" version of the report without the site navigation or chat.

Save as PDF

Opens the print dialog. Choose Save as PDF as the destination. Your coaching notes are included.

Download CSV

Exports the key statistics, team comparisons and strength/development flags as a CSV file.

GitHub integration

Analytics Model Library

The analytics projects behind these templates. Integrated models run in this browser in JavaScript. Demo projects have a working JavaScript demo of the original. Requires Backend projects are Python/R models that need a server. The site never pretends to run them; it only displays their outputs when you include those columns in your CSV.
